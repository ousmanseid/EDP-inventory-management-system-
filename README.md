

Welcome to the UI feature branch! This branch focuses on modernizing the user interface of the Inventory System, making it more beautiful, interactive, and modern.


### Main Dashboard (`MainDashboard.cs`)
- **Modern Color Palette**: Introduced a sleek 3-color palette (Midnight Blue, Ocean Blue, and Pure White).
- **Interactive Sidebar Navigation**: Upgraded the sidebar buttons with improved hover states and seamless transitions.
- **Improved Aesthetics**: 
  - Added linear gradient backgrounds for a sleek look to the sidebar and top panel.
  - Revamped button typography with `Segoe UI`, matching modern design standard principles.
  - Refined active and inactive link states for clear navigation feedback.

### Login Form (`LoginForm.cs`)
- Maintained a streamlined, modern look cohesive with the main dashboard.
- Small structural updates for codebase maintenance.

## 🚀 How to Run
Ensure you have the .NET development environment properly configured, and simply run the project build (or run `InventorySystem.sln` if launching from Visual Studio).

## 💡 What's Next?
Stay tuned as we bring these aesthetics into individual form views like the `ProductForm`, `StockForm`, and other essential parts of our application!
